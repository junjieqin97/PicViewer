# PicViewer 国际化约定

## 目标

- 首期支持 `zh_CN` 与 `en`。
- 使用 `.ts/.qm + QTranslator`。
- 不支持运行时切换语言，启动时确定语言。

## 语言选择规则

优先级如下：

1. 环境变量 `PICVIEWER_LANG`
2. 系统语言 `QLocale.system().name()`
3. 默认 `zh_CN`

支持的映射：

- `zh` / `zh_CN` / `zh-CN` -> `zh_CN`
- `en` / `en_US` / `en-GB` -> `en`
- 其他值 -> 视为未设置

## 文本提取与翻译文件

- 翻译源目录：`src/pic_viewer/ui/resources/i18n`
- 翻译文件：
  - `picviewer_zh_CN.ts`
  - `picviewer_en.ts`

更新 TS：

```bash
scripts/i18n/update_ts.sh
```

生成 QM：

```bash
scripts/i18n/build_qm.sh
```

## 仓库与发布约定

- 仓库只提交 `.ts`。
- CI/打包阶段生成 `.qm` 并放入发布产物。
- 本地源码运行若无英文 `.qm`，会自动回退中文，不阻塞开发。

## 新增文案规范

- 所有用户可见文本必须走翻译函数，不得直接硬编码到 UI 展示路径。
- UI 层统一使用 `_tr(...)`。
- 服务层/领域层保持无 Qt 依赖；来自后端的固定提示语在 Controller 层做本地化映射。

## 发布前检查

1. 执行 `scripts/i18n/update_ts.sh`，确认无遗漏文本。
2. 执行 `scripts/i18n/build_qm.sh`，确认 `picviewer_en.qm` 可生成。
3. 用 `PICVIEWER_LANG=en` 启动验证菜单、标签、弹窗、状态栏、元数据空态均为英文。
